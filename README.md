## 🚀 Установка и запуск

### Установка

**Программу не нужно устанавливать** — просто распакуйте архив и запустите `RimLangKit.exe` из любой папки.

### Удаление

1. Удалите папку с программой
2. (Опционально) Удалите настройки из:
   ```
   C:\Users\%username%\AppData\Local\OliveWizard
   ```

### ⚡ Быстрый старт для пользователей

1. [Скачайте последнюю версию](https://github.com/OneCodeUnit/RimLangKit/releases/latest)
2. Распакуйте архив
3. Запустите `RimLangKit.exe`
4. Укажите путь к папке RimWorld (где находятся `Data` и `RimWorldWin64.exe`)
5. Нажмите "Обновить перевод"
6. В игре выберите язык **"Russian (GitHub)"** вместо "Russian (Русский)"
7. Готово!

### 🔧 Быстрый старт для переводчиков

1. [Скачайте последнюю версию](https://github.com/OneCodeUnit/RimLangKit/releases/latest)
2. Распакуйте архив
3. Запустите `RimLangKit.exe`
4. Переключитесь на вкладку **"Для переводчиков"**
5. Выберите папку с вашим переводом
6. Выберите нужное действие из списка
7. Нажмите "Запуск"

## 👥 Для пользователей

### Работа программы

Сообщество начинает работу над переводом только после выхода обновления игры, и процесс может занимать значительное время. Более того, перевод попадает в саму игру с большой задержкой.

**RimLangKit решает эту проблему**, позволяя скачать самую последнюю версию перевода напрямую из GitHub и сразу добавить его в игру.

#### Как это работает:

1. Укажите путь к корневой папке игры (где есть папка `Data` и файл `RimWorldWin64.exe`)
2. Программа проверит актуальную версию перевода на GitHub
3. Если есть обновления — скачает и установит их
4. В игре выберите язык **"Russian (GitHub)"** вместо "Russian (Русский)"

#### Преимущества перед [консольным скриптом](https://github.com/asidsx/RimWorldRuslangAutoUpdater/blob/main/auto.bat):

- ✅ Ничего не скачивает, если нет новой версии
- ✅ Не записывает данные лишний раз
- ✅ Может использоваться для обновления не только русской локализации
- ✅ Поддерживает все DLC и будущие дополнения
- ✅ Удобный графический интерфейс

### Дополнительные возможности

#### Выбор репозитория

**Поле:** `Ludeon/RimWorld-ru`

Позволяет выбрать другой репозиторий для загрузки языка (это часть адреса GitHub).

**Пример:** Для адреса `https://github.com/Ludeon/RimWorld-ru` нужно указать `Ludeon/RimWorld-ru`

**Применение:**
- Загрузка других языков
- Использование собственных форков перевода
- Тестирование альтернативных версий локализации

#### Настройка названия языка

**Поле:** `Russian (GitHub)`

Позволяет задать название языка в игре:
- **`Russian`** — название языка (менять только для других языков)
- **`(GitHub)`** — произвольная метка для идентификации источника перевода

#### Удаление перевода

**Кнопка:** "Удалить перевод"

- Сбрасывает номер текущей версии перевода
- Удаляет папки с выбранным языком

#### Сброс настроек

**Кнопка:** "Сброс настроек"

Возвращает все настройки к значениям по умолчанию (как при первом запуске).

### Обратите внимание

⚠️ **Не стоит проверять обновления локализации слишком часто** (речь о десятках раз в час), так как это может привести к временной блокировке по IP со стороны GitHub API.

## 🛠️ Для переводчиков

### Работа программы

Программа позволяет выбрать папку и применить ко всем файлам в ней одно из действий:

> **Важно!** Большинство действий требуют, чтобы файлы уже были обработаны **RimTrans** или его аналогом.

---

### Добавить комментарии

Программа добавит во все `.xml` файлы в выбранной папке и во всех подпапках комментарии с исходным текстом.

**Зачем это нужно:** Помогает не забыть, что вы переводите, и упрощает проверку перевода.

**⚠️ Требование:** Файлы должны быть обработаны RimTrans или его аналогом.

#### Пример

**Исходный текст:**
```xml
<VBE_StartInsertion>Bring Syrup</VBE_StartInsertion>
<VBE_StartInsertionDesc>Bring a syrup to the soda fountain to start processing</VBE_StartInsertionDesc>
<VBE_CancelBringingSyrup>Cancel Bringing Syrup</VBE_CancelBringingSyrup>
<VBE_CancelBringingSyrupDesc>Cancel bringing syrup to the soda fountain.</VBE_CancelBringingSyrupDesc>
```

**Обработанный текст:**
```xml
<!-- EN: Bring Syrup -->
<VBE_StartInsertion>Bring Syrup</VBE_StartInsertion>
<!-- EN: Bring a syrup to the soda fountain to start processing -->
<VBE_StartInsertionDesc>Bring a syrup to the soda fountain to start processing</VBE_StartInsertionDesc>
<!-- EN: Cancel Bringing Syrup -->
<VBE_CancelBringingSyrup>Cancel Bringing Syrup</VBE_CancelBringingSyrup>
<!-- EN: Cancel bringing syrup to the soda fountain. -->
<VBE_CancelBringingSyrupDesc>Cancel bringing syrup to the soda fountain.</VBE_CancelBringingSyrupDesc>
```

---

### Избавиться от одинаковых имен файлов

Программа добавит всем `.xml` файлам приписку к имени, соответствующую имени папки перед `Languages`.

**Зачем это нужно:** Позволяет избежать конфликтов при объединении переводов модов.

#### Пример

**Исходный файл:**
```
Vanilla Furniture Expanded Russian Language pack\Architect\Languages\Russian\DefInjected\TerrainDef\Terrain_Floors_Arch.xml
```

**Обработанный файл:**
```
Vanilla Furniture Expanded Russian Language pack\Architect\Languages\Russian\DefInjected\TerrainDef\Terrain_Floors_Arch_Architect.xml
```

---

### Транскрипция имен

Программа прочитает все `.txt` файлы и создаст дубли с припиской `_NEW`, текст в которых будет транслитерирован согласно правилам из словаря.

**Зачем это нужно:** Полезно для перевода списков имен персонажей.

#### Структура словаря (`dictionary.txt`)

Словарь состоит из нескольких строк:

1. Четырехбуквенные части
2. Трехбуквенные части
3. Двухбуквенные части
4. Однобуквенные части
5. Не имеющие транскрипции части
6. Правила для начала слова
7. Правила для конца слова

**Порядок проверки:** 6 → 7 → 5 → 1 → 2 → 3 → 4

---

### Создать Case, Plural и Gender файлы

Для корректного склонения названий объектов игре требуются дополнительные файлы:

- **`Case.txt`** — склонение слова по падежам
- **`Plural.txt`** — множественное число
- **`Female.txt`, `Male.txt`, `Neuter.txt`, `Plural.txt`** в папке `Gender` — распределение слов по родам и числам

**⚠️ Требования:**
- Файлы должны быть обработаны RimTrans или его аналогом
- Для склонения используется API [веб-сервиса «Морфер» 3.0](https://morpher.ru/ws3/)

#### Ограничения API Морфер

- **Лимит:** 100 запросов в сутки на IP-адрес
- Если запросов не хватает для обработки текущего defType, работа не будет продолжена
- При повторном запросе лучше убрать папки с уже обработанными defType

#### Файлы результата

Все, что программа не смогла опознать, помещается в файл **`Undefined.txt`**.

> **Примечание:** Программа может добавить немного больше объектов, чем требуется. Не стесняйтесь удалять лишнее.

#### Использование

Программе нужно указать **корневую папку перевода**.

---

### Исправление кодировки

При выгрузке из внешних сервисов (например, Crowdin) файлы скачиваются в неправильной кодировке.

**Что делает программа:**
- ✅ Пересохраняет каждый файл в кодировке **UTF-8 BOM**
- ✅ Устанавливает табуляцию в **два пробела**
- ✅ Устанавливает окончание строк **CRLF**

Это позволит переводу соответствовать стандарту русской локализации RimWorld.

---

### Анализ тегов

Программа собирает статистику использования тегов и defs в переводе и сохраняет ее в текстовые файлы в папке исполняемого файла.

**⚠️ Требование:** Файлы должны быть обработаны RimTrans или его аналогом.

---

### Поиск сломанных файлов

Позволяет найти в переводе файлы, сломанные по той или иной причине:

- ❌ Не будут считываться игрой
- ❌ Не соответствуют стандартам XML

---

### Поиск изменений в тексте

Позволяет сравнить исходный текст перевода и текущий текст мода.

**⚠️ Требование:** Файлы должны быть обработаны RimTrans или его аналогом.

#### Результаты работы

Результат выводится в текстовые файлы в папке исполняемого файла в формате **defName + новый текст**:

| Файл | Описание |
|------|----------|
| **`ChangedData.txt`** | defName с различающимся текстом в моде и переводе<br>⚠️ **Обратите внимание:** Обновления мода изменили текст |
| **`TranslationData.txt`** | defName *из перевода*, у которых не нашлось совпадений в *файлах мода*<br>ℹ️ Необязательно ошибка — инструмент перевода мог вытянуть не всё |
| **`ModData.txt`** | defName *из мода*, у которых не нашлось совпадений в *файлах перевода*<br>ℹ️ Необязательно ошибка — инструмент перевода мог вытянуть лишнее |

> **Примечание:** defName иногда бывают неуникальны. В таком случае к ним при записи добавляются 4 уникальные цифры. Из-за этого такие строки проверить не получится.

#### Что не записывается

defName с совпадающим текстом в моде и переводе не записываются.

---

### Предварительный перевод

В переводах часто встречаются одинаковые слова, на которые уже ранее был сделан перевод в прошлых работах.

**Примеры:** "приклад" у оружия, "левая лапа" у животного.

**⚠️ Требования:**
- Файлы должны быть обработаны RimTrans или его аналогом
- У исходного текста должны быть проставлены комментарии с исходным текстом

#### Как использовать

1. **"Выбрать источник данных"** — укажите папку с существующими переводами
2. Программа найдет текст, который совпадает с текстом в текущем переводе
3. Автоматически заполнит найденные совпадения

## 🔨 Сборка из исходников

### Требования

- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- Visual Studio 2022 или JetBrains Rider (опционально)

### Автоматическая сборка

Запустите скрипт:

```batch
!publish.bat
```

Готовые файлы появятся в папке `bin\Release\net9.0-windows7.0\win-x64\publish\`.

### Ручная сборка

```batch
dotnet restore
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained false
```

Для self-contained версии (без требования установленного .NET):

```batch
dotnet publish -c Release -r win-x64 --self-contained true
```

## ❓ FAQ

### Программа не запускается

**Решение:**
1. Убедитесь, что установлен [.NET 9](https://dotnet.microsoft.com/download/dotnet/9.0)
2. Попробуйте версию `.7z` вместо `.exe`
3. Проверьте, не блокирует ли антивирус программу

### Не удается обновить перевод

**Возможные причины:**
- Неправильно указан путь к игре (должна быть корневая папка с `RimWorldWin64.exe`)
- Проблемы с подключением к GitHub
- Временная блокировка IP за частые запросы

### Перевод не появляется в игре

**Решение:**
1. Убедитесь, что выбрали язык **"Russian (GitHub)"**, а не "Russian (Русский)"
2. Перезапустите игру
3. Проверьте, что путь к игре указан правильно

### Морфер не склоняет слова

**Решение:**
- Проверьте подключение к интернету
- Возможно, исчерпан лимит запросов (100 в сутки на IP)
- Попробуйте на следующий день или используйте VPN

### Ошибка при обработке файлов

**Решение:**
1. Убедитесь, что файлы обработаны RimTrans
2. Проверьте правильность XML-разметки
3. Проверьте кодировку файлов (должна быть UTF-8 BOM)
